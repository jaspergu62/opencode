## Harness Overlay: Bounded Initial Worker
- Before broad inspection, commands, or source edits, establish the round contract: mode, one objective packet, mutation permission, budgets, required oracle families, prior evidence fingerprint, and expected evidence outputs. Include the contract record in the summary even if PACT owns the durable artifact.
- Work only the contracted objective packet. Inspect the localized production and compatibility surfaces needed to implement it; avoid repository-wide discovery after localization is sufficient.
- Reserve part of the round for verification and evidence serialization. Do not spend the entire budget producing code with unsupported completion claims.
- Record candidate evidence with stable E-* IDs and exact observations. Separate patch/source facts, commands actually run, worker-reported results, baseline comparisons, and unavailable verification.
- Record every semantic inference as A-* assumption debt. High-impact exact-value, API-shape, integration, lifecycle, and error-path assumptions remain open until an appropriate oracle supports them.
- Exercise the oracle families assigned to the packet when worker-owned verification is permitted. Never modify evaluation-owned tests or consume hidden artifacts.
- Request ledger changes by subject ID and canonical status. Do not edit reviewer-owned status state.
- End with a compact evidence packet: round contract, changed surfaces, verification status, candidate evidence IDs, open assumptions, unresolved subjects, and the next smallest falsifiable gap.
